# Notes Markdown 与数学公式

公开阅读页和后台编辑预览使用相同的 Markdown 渲染器。支持标题、列表、引用、链接、图片、代码块、GFM 表格、删除线，以及 KaTeX 数学公式。

## 公式写法

行内公式：`$V_i$` 或 `\(V_i\)`。

独立公式可以使用以下两种写法：

```latex
$$
\mathcal{L} = \sum_{i=1}^{n} \frac{V_i}{\|V_i\|_2}
$$
```

```latex
\[
V_i^{(t+1)} = V_i^{(t)} + \alpha \nabla_{V_i}\mathcal{L}
\]
```

`V\_i` 是普通 Markdown 中对下划线的转义，显示为文本 `V_i`，不会自动成为数学下标。要显示数学下标请使用 `$V_i$`；公式内的 `\_` 则表示字面下划线，不应写成 `$V\_i$` 来表达下标。

代码块和反引号中的公式保持原样，例如 `` `$V_i$` ``。普通价格如 `$5` 不会被当成公式。未闭合的公式保留为文本；不支持的 TeX 命令显示错误提示，不影响整篇笔记。

长公式可在自身区域横向滚动，不会撑宽正文。字体与排版库随应用打包，不依赖外部 CDN。HTML 仍经安全过滤，公式不允许执行脚本或可信 HTML 命令。

通过 JSON API 写入时，反斜杠须遵循 JSON 转义。例如发送 `{"content":"行内公式 \\(V_i\\)"}`；使用 Python `json.dumps` 等序列化器处理，不要手工反复加转义。数据库保存的是原始 Markdown，不需要保存渲染后的 HTML。
